---
description: Inicia o processo completo gateado para uma feature ou mudança
argument-hint: [descrição]
---

`/feature` é a entrada do processo completo; não repita o Gate 0.

1. Se `$ARGUMENTS` estiver vazio, pergunte o tópico com a ask do harness e espere.
2. Invoque o skill `dockeeper-process` no modo completo com o tópico.
3. Comece pelo `brainstorming`; use a ask para as perguntas.
4. Não edite antes de a spec e o plano passarem pelos gates.
